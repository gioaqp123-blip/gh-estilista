# GH Estilista

Landing page de GH Estilista construida con React y Vite. La interfaz conserva el diseño original y la agenda continúa generando solicitudes para WhatsApp sin backend.

## Documentación

La documentación del frontend está en [docs/frontend](docs/frontend/README.md), con especial detalle del sistema de branding en [docs/frontend/branding.md](docs/frontend/branding.md).

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

El build se genera en `deploy/`, que debe publicarse como raíz del sitio.
