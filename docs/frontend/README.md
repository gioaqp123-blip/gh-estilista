# Documentación del frontend

Esta carpeta describe la identidad visual, la estructura React y los flujos que no deben romperse al mantener GH Estilista.

## Documentos

- [Branding y sistema visual](branding.md): identidad, paleta, tipografías, tono, composición, botones, imágenes, responsive y reglas para no alterar el aspecto actual.
- [Arquitectura frontend](architecture.md): entrada de la aplicación, componentes, datos, estilos, assets y comandos de desarrollo.
- [Agenda y WhatsApp](booking.md): estado, calendario, horarios, `localStorage`, validaciones y formato del mensaje.

## Principio de mantenimiento

La migración a React es estructural, no un rediseño. Antes de cambiar clases, medidas, colores, fuentes o contenido comercial, debe comprobarse que el cambio es intencional y que no afecta la composición de escritorio y móvil.
